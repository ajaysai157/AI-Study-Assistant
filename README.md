## 🚀 About

StudyFlow is an AI-powered study assistant designed exclusively for students.

Instead of managing multiple apps for notes, flashcards, quizzes, and revision, StudyFlow brings everything into one intelligent workspace.

The goal is not just to generate AI content—it is to guide students through an effective learning journey.

---

## ✨ Vision

> **Learn Smarter. Learn Better.**

StudyFlow focuses on improving the complete learning experience by helping students:

- 📄 Organize study notes
- 🤖 Generate AI summaries
- 🧠 Create flashcards automatically
- ❓ Practice with AI-generated quizzes
- 📈 Track study progress
- 🎯 Stay focused on learning instead of managing files

## 🖥️ Getting Started

Clone the repository

```bash
git clone https://github.com/ajaysai157/AI-Study-Assistant.git
```

Go into the project

```bash
cd AI-Study-Assistant/client
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

---

## 🎯 Project Philosophy

StudyFlow is **not just another AI tool**.

The objective is to build a platform that encourages students to actually understand and retain concepts rather than simply consuming AI-generated answers.

The platform is designed around the learning cycle:

```
Upload Notes
      ↓
AI Analysis
      ↓
Smart Summary
      ↓
Flashcards
      ↓
AI Quiz
      ↓
Track Progress
      ↓
Learn Better
```
